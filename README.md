# 悦己分享机器人

合规 Telegram 资源分享机器人基础框架（Python + aiogram）。

## 功能
- 底部键盘：我的信息 / 每日签到 / 购买积分 / 帮助
- 用户信息：用户名、当前积分、累计消费、已解锁数量
- 随机资源推送 + 积分解锁
- 每日签到
- 购买积分（多档位按钮）
- 帮助说明

## 安装与运行
1. 安装依赖：`pip install -r requirements.txt`
2. 复制 `.env.example` 为 `.env`，填写 `BOT_TOKEN`
3. 运行：`python bot.py`

建议用 screen 或 systemd 在服务器上保持运行。

## 注意
仅供合规内容使用，请勿用于违规资源。


## 管理员设置中心

管理员可在机器人内打开「⚙️ 设置中心」，持久化调整新用户初始积分、每日签到奖励、积分档位、随机文件夹数量、文件夹解锁价格、欢迎/帮助文案及欢迎图片。设置保存在 SQLite 的 `config` 表中，重启后保留。

「用户与积分管理」可按用户 ID/用户名搜索，增减积分，并封禁/解封用户。浏览时长可设置为 3、5、10 分钟、自定义分钟或不限时，并选择到期后限制全部资源还是只限制视频，以及管理员是否免限时。计时从用户点击「开始浏览资源」时开始；到期后阻止新的受限资源发送，已发送的内容无法撤回。

首次初始化会为现有用户表补充封禁字段，并新增浏览会话表，不会删除现有用户、积分、兑换码或解锁记录。购买积分按钮目前只展示档位并提示联系管理员，真实在线支付尚未接入；请仅向完成付款的用户发放兑换码。

## 自动检查

GitHub Actions 会运行 Python 语法检查和 SQLite 配置/迁移烟雾测试。部署前仍应在测试环境检查 Telegram 实际按钮、频道复制权限和资源分页行为。
